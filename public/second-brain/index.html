我的不完美「第二大脑」

My Imperfect Second Brain

你有没有想过，Elon Musk、Mark Zuckerberg 这些人，是不是都有一套特别厉害的笔记系统，才能同时管理好几家公司？

网上一堆文章教你番茄工作法、怎么开会更高效——却很少有人告诉你，答案可能没有你想的那么玄乎。

我是 Eddy，一个外贸人、内容创作者、多元兴趣者。
这是我拆了又拼、用了很多年的笔记系统——粗糙，但真的在用。

01 · 两种声音

第二大脑到底是为了什么？

前几年"第二大脑"这个词很火，网上基本是两种声音。没有哪种是对的、哪种是错的——适合你的，就是对的。

ACTIONABILITY

行动派

记笔记是为了产出、为了行动。笔记能不能真的推动你去做点什么，才是重点——大部分博主和《打造第二大脑》的作者都强调这个。

MEMO & ARCHIVE

存档派

单纯拿来当备忘录，存点资料、留个记录。不需要因为某本书说"重点是行动"，就觉得自己存资料是错的。

PARA 和 CODE，不是一回事

这两本书绕不开一个词：PARA，Tiago Forte 提出的"数字知识管理法"。但书里其实讲了两套不同的东西，很多人会搞混，包括我。

PARA 是一个分类法——这条笔记该放哪个抽屉。把处理流程和分类方法打包成一个系统来卖，是这本书最大的卖点，但也让第二大脑变得特别复杂。

03 · 用久了会卡在哪

我用 PARA 的四五年

Project 太笼统——一个 project 通常是一组工作，很难用一页笔记装下，最后大部分内容都堆去了 Area 和 Resources。

Area（长期不紧急，比如人际关系、健康管理）和 Resources（未来可能用到的资料）之间，界限也很模糊。体检记录该放哪？高胆固醇的问题又该放哪？

"不是我笨，是这套分类法本来就不是拿来一字不差照抄的。"

太较真，可玩性太强，很容易掉进整理笔记的陷阱，反而盖过了真正要解决问题这件事。

04 · 一个常被搞混的概念

卡片盒笔记法，不是 PARA

Zettelkasten 卡片盒笔记法，是德国社会学家 Niklas Luhmann 发明的。核心逻辑：每张笔记只写一个独立想法，靠双向链接互相连接，而不是靠文件夹分类。

后来德国教授 Sönke Ahrens 写了《How to Take Smart Notes》，把这套方法重新梳理讲透，在英文世界又火了一波。

PARA 先分类，服务当下项目；卡片盒不分类，靠链接让想法自己长出新东西——两者哲学几乎相反，不是一回事。

但两者也有重合：用 Notion 之类的软件把笔记串联起来，就能做到 Incremental Writing 渐进式写作，不必从零开始，把知识点一条一条串起来。

05 · 换软件这件事

从 Evernote 到 Obsidian

这几年换过不少笔记软件，每次换的原因都很朴素——不是软件不好，只是那个阶段不趁手。

Evernote
最早的起点
Notion
PARA 系统主力
Apple Notes / Bear
轻量随手记
Obsidian
本地 Markdown + 云同步

为什么现在用 Obsidian？它用本地 Markdown 文件，我存在自己的云上——手机丢了、电脑被偷，记录都不会丢。是一种反脆弱，也很适合长期主义者。而且轻，快，用起来爽，仅此而已。

软件几乎都能互相替代，每个软件的强项不一样，但真正决定效果的，从来不是软件本身。

06 · 换了软件，顺手也换了系统

ACE：Nick Milo 的三分法

说来好笑，我竟然因为换了个软件，就换了个系统——这不代表 PARA 不堪用，只是我一直在根据自己的习惯改善、微调，改到了现在这个样子。

A

Atlas

已经掌握、想长期留存参考的东西——工作记录、备忘、学到的知识。

名字来自 16 世纪制图师麦卡托，地图集封面那个扛着地球的巨神。
C

Calendar

PARA 里没有的东西。用时间归档：日记、杂思、周复盘、会议记录，按日期存放，方便以后搜索。

脑子里的念头倒进去，也能降低焦虑。
E

Effort

最重要的一栏，其实就是 PARA 里的 Project——你现在正在做的事、正在推进的项目。

我不是在推荐 Obsidian，也不是在推荐 ACE。说白了它跟 PARA 换汤不换药，只是换了一个更顺手的起点，接着改而已。

08 · 别再问该用哪个 App 了

问自己三个问题就够了

封面上那五个 app——Obsidian、日历、待办、Slax、相册——其实都不重要。你可能是苹果用户，也可能是 Android 用户，软件都能替换，用得爽就行。

Q1

你每天到底做什么？

最简单的答案就是 To Do。今天要做的事、日历上的行程、相册里的各种截图，都汇总进来。

举例 ▾

每天先看一遍看板，照着它展开一天的工作和生活。

Q2

怎么快速捕捉想法？

不管你是内容创作者还是上班族，都需要快速捕捉。工具不重要，重点是要够快、够轻。

举例 ▾

看到有意思的东西就截图，吸收完就删；开车时有想法，打开语音输入让 AI 转文字；在电脑前就用 Quick Capture。整理的时间点不重要，随手记的动作要够轻，你才会真的去做。

Q3

怎么备忘？

长期结构化信息——银行信息、工作备忘录、产品笔记、财务记录，直接丢进 Atlas。

写在最后

第二大脑，从来不是一个 App

也许那些很复杂、很完美的第二大脑系统，从来都不存在。如果你能回答上面那三个问题，既能管理个人知识系统，又能处理工作、推进项目——作为普通人，这就真的很够用了。

第二大脑从来不是只靠一个 app，而是用一套简单的系统，去管理你的人生。
